# قالب فایل مقاله‌های بلاگ کلاود ایران

هر مقاله یک فایل Markdown در `content/blog/<slug>.md` است. ساخت صفحه‌ها خودکار است (`npm run build` → `tools/build-blog.mjs`).

## Frontmatter (دقیقاً همین کلیدها، هر کلید در یک خط، بدون نقل‌قول)

```
---
slug: claude-api
title: عنوان H1 مقاله (طبیعی و کامل، تا ~۷۰ نویسه)
seoTitle: عنوان تگ title بدون نام برند (≤ ۵۸ نویسه؛ « | کلاود ایران» خودکار اضافه می‌شود)
description: متای توضیحات (۱۲۰ تا ۱۵۵ نویسه)
excerpt: خلاصهٔ یک‌جمله‌ای برای کارت مقاله (≤ ۱۶۰ نویسه)
cluster: یکی از: مبانی | هزینه و توکن | مدل‌ها | مقایسه | توسعه | امنیت
keywords: کلیدواژه اصلی, فرعی ۱, فرعی ۲
date: 2026-11-23
updated: 2026-11-23
featured: true   (فقط برای مقالهٔ ستون؛ بقیه این خط را ندارند)
---
```

## بدنه

- با یک یا دو پاراگراف مقدمه شروع شود؛ **H1 ننویسید** (از title ساخته می‌شود).
- ساختار با `##` (H2) و `###` (H3). هر H2 یک پرسش یا موضوع روشن. ۵ تا ۹ H2.
- پاراگراف‌ها کوتاه (۲ تا ۵ جمله). فهرست، جدول Markdown و بلوک کد مجازند.
- بلوک کد با زبان: ```` ```python ````، ```` ```bash ````، ```` ```javascript ````، ```` ```json ````. کامنت‌های داخل کد انگلیسی.
  - در نمونه‌کدها **آدرس واقعی api.anthropic.com را می‌شود آورد** (این مستندات عمومی است)، اما هیچ ادعایی نکنید که از ایران قابل دسترسی است. کلید را همیشه از متغیر محیطی بخوانید.
- نکتهٔ برجسته: `> **نکته:** متن` — یا `> **هشدار:** متن` — یا `> **خلاصه:** متن`.
- لینک درونی: `[متن لینک](/blog/<slug>/)` یا `[متن](/#features)`؛ لینک بیرونی فقط به منابع رسمی (docs.claude.com / docs.anthropic.com / anthropic.com).
- اصطلاحات انگلیسی را در اولین بار با معادل فارسی بیاورید: «توکن (Token)».
- اعداد فارسی در متن فارسی (۲۰۰ هزار توکن)، اعداد لاتین فقط داخل کد.
- نیم‌فاصله درست: «می‌شود»، «توسعه‌دهنده»، «درخواست‌ها».

## بخش سؤالات متداول (آخر مقاله، اجباری)

```

پاسخ در یک پاراگراف (۲ تا ۴ جمله، بدون لینک و بدون فهرست).

### پرسش دوم؟
پاسخ.
```

این بخش خودکار به FAQ آکاردئونی و اسکیمای FAQPage تبدیل می‌شود. ۳ تا ۵ پرسش.

## قواعد صداقت (غیرقابل‌مذاکره)

- هیچ قیمت، نرخ، درصد تخفیف، تاریخ عرضه، آمار ساختگی، مشتری یا نقل‌قول ساختگی ننویسید.
- دربارهٔ قابلیت‌های Claude فقط چیزی بنویسید که در مستندات رسمی هست؛ اگر مطمئن نیستید، کلی بنویسید («پنجرهٔ زمینهٔ بزرگ» به‌جای عدد دقیق) یا ارجاع به مستندات رسمی بدهید.
- کلاود ایران «در مرحلهٔ پیش‌عرضه» است، وابسته به Anthropic نیست و راه‌اندازی آن مشروط به تأمین مورد تأیید و قرارداد است. هیچ‌وقت ننویسید «فعال است»، «همین حالا ثبت‌نام کنید و استفاده کنید» یا «رسمی».
- هیچ محتوایی دربارهٔ دور زدن محدودیت منطقه‌ای، فیلترشکن، VPN، خرید اکانت، اکانت اشتراکی، «Claude در ایران» یا تحریم ننویسید.
- لحن: فنی، روشن، محترمانه، بدون اغراق تبلیغاتی. کلاود ایران را حداکثر ۲ بار و فقط جایی که طبیعی است نام ببرید؛ CTA پایانی را قالب خودکار اضافه می‌کند.
